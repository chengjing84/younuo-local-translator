# 三个推荐模型怎么选

核对日期：2026-09-12。优诺推荐下面三个模型，安装一个即可；也允许选择 `ollama list` 中的其他模型。默认使用 Qwen3.5 4B。

## 优缺点与安装命令

| 模型                     | 优点与适合场景                    | 缺点与实际观察                                               | 下载体积 |
| ------------------------ | --------------------------------- | ------------------------------------------------------------ | -------- |
| **Qwen2.5 3B：极致速度** | 预热最快，适合快速了解网页大意    | 样本出现部分英文未译，并直接回答待翻译问题；重要内容必须对照 | 约 1.9GB |
| **Qwen3.5 4B：日常推荐** | 36 次扩展样本稳定，速度和质量平衡 | 固定术语边界曾有多余空格，现已在恢复层修正；仍不代表零误译   | 约 3.4GB |
| **Qwen3.5 9B：质量悠闲** | 本项目样本语义较稳，适合重要段落  | 占用最大、等待最长，质量提升不保证覆盖所有文本               | 约 6.6GB |

下载体积来自 Ollama 当前标签：[4B](https://ollama.com/library/qwen3.5:4b)、[9B](https://ollama.com/library/qwen3.5:9b)、[3B](https://ollama.com/library/qwen2.5/tags)。标签可能更新，下载量不等于运行内存或显存占用。

在 PowerShell 中选择对应的一条执行：

```powershell
# 日常推荐
ollama pull qwen3.5:4b

# 质量悠闲
ollama pull qwen3.5:9b

# 极致速度
ollama pull qwen2.5:3b
```

下载完成后执行 `ollama list`，再到优诺连接页点击“检查连接”。设置页也可填写其他已安装模型的完整名称；自定义模型没有经过本项目质量验证。

## 本项目的速度记录

| 模型                           | 8 条短句平均耗时 | 最短～最长    |
| ------------------------------ | ---------------- | ------------- |
| Qwen3.5 9B                     | 2.12 秒          | 1.55～2.89 秒 |
| Qwen2.5 3B                     | 0.67 秒          | 0.41～0.91 秒 |
| Qwen3 1.7B（历史对照，不推荐） | 0.43 秒          | 0.33～0.56 秒 |

数据取自 [原始样本](model-samples.json)，包含否定、先后顺序、术语、URL 和多语种短句。没有记录完整硬件、冷热启动控制和重复轮次，因此只能描述这次观察，不能换算成你电脑的速度、稳定倍数或整页完成时间。质量边界见 [验证记录](VALIDATION.md)。

网页可能有几十个文本节点，排队、输出长度和首次加载都会增加等待。优诺目前按节点翻译、前端单批最多 2 段，后台串行执行模型推理，并显式设置 16K 上下文。Qwen3/3.5 请求关闭思考输出。下载更小模型通常有助于降低占用，但不能只按参数量判断实际体验。

## 对电脑的要求

以下是为浏览器与模型一起运行预留余量的**规划建议，不是已通过多硬件测试的最低配置**。本项目当前使用 16K 上下文，不能套用网上只有短上下文时的显存数字。

| 模型       | 系统内存建议                   | 独立显卡容量参考                                           |
| ---------- | ------------------------------ | ---------------------------------------------------------- |
| Qwen3.5 9B | 16GB 起评估，32GB 多任务更宽裕 | 优先考虑 12GB 或以上；8GB 可能吃紧或部分落到 CPU，必须实测 |
| Qwen2.5 3B | 建议 16GB                      | 4～6GB 档位可作为评估起点，仍需考虑上下文和其他软件占用    |

显存容量只决定能装下多少，不等于算力。显卡型号、驱动支持、内存带宽和游戏/剪辑/其他 AI 软件的占用都会影响表现。集成显卡或统一内存不能直接套用独显表格；CPU 可以承担推理，但不把纯 CPU 的整页流畅体验作为承诺。

在翻译正在进行时执行：

```powershell
ollama ps
```

查看 `PROCESSOR`：`100% GPU` 为完全加载到 GPU；`100% CPU` 为系统内存运行；混合比例代表部分卸载到 CPU。显卡有余量也不代表短句必然瞬间完成。[Ollama 官方说明](https://docs.ollama.com/faq#how-can-i-tell-if-my-model-was-loaded-onto-the-gpu)

不需要继续占用某个模型时，可以先在优诺停止翻译，再释放它的运行内存；这不会删除下载文件：

```powershell
ollama stop qwen3.5:9b
```

## NSFW 能力如何理解

这里讨论的是已有网页文字的翻译，不是图片识别或内容生成。NSFW 也不是一个统一能力指标，成人题材、露骨性描写、粗口和暴力文字可能有不同表现。

**三个官方标签目前都不标注“已验证支持 NSFW”。**截至核对日期，在下面的官方模型卡中未找到对这类网页翻译稳定保真、不拒答的承诺；本项目也没有相应验收数据。因此不列出“支持”标识，但这也不等于断言所有相关文字都无法翻译。

本地运行不自动等于无拒答。实际输出可能拒绝、删减、弱化或改写，优诺的数量和格式校验不能识别所有这类语义变化。不要把普通文本样本通过当成成人内容支持证明。本项目不提供解除模型限制的开关。

官方模型卡：[Qwen3.5 9B](https://huggingface.co/Qwen/Qwen3.5-9B)、[Qwen2.5 3B Instruct](https://huggingface.co/Qwen/Qwen2.5-3B-Instruct)、[Qwen3 1.7B](https://huggingface.co/Qwen/Qwen3-1.7B)。

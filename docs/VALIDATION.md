# 0.8.0 验证记录

日期：2026-09-11。此记录区分回归验证和模型质量，不将 mock 成功视为真实模型准确。

## 自动化

- Python：19 项单元/HTTP 集成测试。覆盖令牌、来源拒绝、畸形 JSON、类型与长度、润色输入、术语占位、无效输出、截断、缓存与繁忙响应。
- JavaScript：25 项测试通过，涵盖后台会话、并发偏好写入、导入验证、原文恢复、SPA 更新、停止与晚到响应、术语缓存、编辑区排除、内部滚动、选区范围、首启与设置交互。
- 真实侧载：通过隔离 Edge profile 加载真实 manifest/background/content/options，使用本机 HTTP 页面；只替换模型 fetch 响应。验证同站两个标签页翻译、停止恢复及跨来源不继承。
- 10,000 文本节点合成页面：记录首轮扫描到发出请求耗时，并断言单批请求不超过 2 段。这不是长期内存或复杂站点性能基准。
- UI：本机 Edge 渲染弹窗、设置、连接页；检查脚本错误、400px 宽度溢出、缺模型不能完成、模型自动选择及无效导入不覆盖设置。

## 真实模型样本

通过本机 Ollama 各执行 8 条样本，含先后顺序、否定、数字与 URL、术语、中文译英文、英文译日文/韩文、包含指令的原文。脚本：`python tools/model-smoke.py`。生成结果随模型版本、量化、硬件和上下文变化。

| 模型       | 本次观察                                                                                    | 定位             |
| ---------- | ------------------------------------------------------------------------------------------- | ---------------- |
| Qwen3.5 9B | 8 条均返回符合格式的可用输出；本次顺序、否定、URL、术语反例未再出现。部分术语附近空格可优化 | 推荐             |
| Qwen2.5 3B | 数字/URL 样本有部分英文未译；带指令的文本被回答而非完整翻译                                 | 兼容选项，需核对 |
| Qwen3 1.7B | “关闭前保存”仍被译成“保存前关闭”                                                            | 试验选项         |

这不是大规模盲测，也不是专业母语者对所有语种的准确率评估。结构化输出、术语和 URL 校验只保护可检测的格式约束，不能证明语义准确。

本次原始样本及耗时见 [model-samples.json](model-samples.json)。耗时来自本机一次小样本运行，不是跨硬件性能承诺。

使用 Ollama `/api/generate` 的 JSON schema 输出并检查返回类型、数量、非空字符串与截断标记；接口依据：[Ollama Generate 文档](https://docs.ollama.com/api/generate)。

## 发布门槛与未验证项

- 本地运行测试、JS/PowerShell 语法检查、构建 ZIP 并核对文件清单后才交付。
- CI 配置已加入，云端运行结果需以 GitHub 实际执行为准；本地成功不等于 CI 已通过。
- Windows PowerShell 5：脚本语法和打包验证通过；隔离目录内成功创建无 pip 的 Python venv 和 44 字符随机令牌，并确认不可用 Python 会使安装失败。支持显式 PythonPath，避免 PATH 指向错误环境。
- 未运行会改动当前机器自启动注册表的全新安装/卸载流程；没有干净 Windows 虚拟机生命周期验收。
- 未证明所有 SPA/虚拟列表兼容；Shadow DOM、跨域 iframe 自动翻译和超长单文本节点暂不支持。
- 取消请求会防止旧结果回写，但 Ollama 中已开始的推理可能继续。

因此本版本定位为可公开试用的 **0.8.0 Beta**。建议发布时展示真实使用过程和这些边界，避免“零误译”“全站兼容”之类承诺。

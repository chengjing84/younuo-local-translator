# 安装、使用与排错

本教程面向 Windows + Microsoft Edge。命令在 PowerShell 中执行；出现项目相对路径时，先进入解压后的项目根目录，也就是同时包含 `install.cmd`、`extension` 和 `host` 的文件夹。

## 1. 准备环境

| 组件       | 要求                                                                                    | 检查方式                                 |
| ---------- | --------------------------------------------------------------------------------------- | ---------------------------------------- |
| Windows    | Windows 10 22H2 或更新版本、Windows 11；优先使用 64 位环境                              | 系统设置 → 系统 → 关于                   |
| Edge       | 使用当前稳定版，允许开发人员模式加载扩展                                                | 打开 `edge://extensions`                 |
| Python     | 可运行的 Python 3.10+，安装时加入 PATH                                                  | `python --version`                       |
| Ollama     | 使用当前稳定版并保持运行；旧版本可能不识别 Qwen3.5                                      | `ollama --version` 和 `ollama list`      |
| 显卡与内存 | 按所选模型留余量，支持情况取决于显卡与驱动                                              | [三模型配置建议](MODELS.md#对电脑的要求) |
| 磁盘       | 为 Ollama 程序、模型和更新分别留空间；只装 9B 建议预留 15～20GB，三个全装建议 20GB 以上 | 查看模型所在磁盘剩余容量                 |

磁盘数字是容量规划，不是固定安装占用。Ollama 官方目前要求 Windows 10 22H2 或更新版本，程序需至少约 4GB 空间，模型另计；NVIDIA/AMD 加速还需兼容驱动。以 [Windows 安装说明](https://docs.ollama.com/windows) 和 [GPU 支持列表](https://docs.ollama.com/gpu) 为准。

从 [Python 官网](https://www.python.org/downloads/windows/) 和 [Ollama 官网](https://ollama.com/download/windows) 安装。装完重新打开 PowerShell，使 PATH 更新生效。使用插件不需要 Node.js、Git、Docker、PyTorch 或单独安装 Python 的 CUDA 包；后台使用 Python 标准库。

## 2. 下载一个模型

先打开 Ollama 应用，再从下面任选一条；利弊与实测见 [模型对比](MODELS.md)。

```powershell
ollama pull qwen3.5:9b
```

```powershell
ollama pull qwen2.5:3b
```

```powershell
ollama pull qwen3:1.7b
```

```powershell
# 确认完整模型名称已出现
ollama list
```

下载需要联网，完成后本机文字翻译无需云端 API 或付费账号。网页本身仍可能需要联网。若命令提示无法连接 Ollama，先启动应用；只有没有运行后台实例时才需要手动执行 `ollama serve`，已经运行就不要重复启动。

## 3. 初始化优诺

1. 从 [GitHub 仓库](https://github.com/chengjing84/younuo-local-translator) 下载源码 ZIP 并完整解压，或使用项目安装包。不要在 ZIP 预览中运行。
2. 把目录放到准备长期保留的位置，双击 `install.cmd`。
3. 等待出现安装成功。安装器会创建 `host/.venv`、生成 `host/config.json`、启动优诺后台，通过检查后设置当前用户登录自启；不会替你安装 Ollama 或下载模型。

如果电脑有多个 Python，或 `python` 指向不可用环境，在项目根目录显式指定解释器：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\install.ps1 -PythonPath "C:\你的Python目录\python.exe"
```

这里要填实际存在的 `python.exe` 路径。初始化成功后不必每次运行安装器；日常手动启动使用 `start-host.cmd`。

## 4. 加载 Edge 扩展并连接

1. 在 Edge 地址栏输入 `edge://extensions`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择项目内的 **extension** 文件夹，不是项目根目录。
3. 在扩展菜单中固定优诺，打开弹窗进入“连接设置”。
4. 用记事本打开 `host/config.json`，找到 `port` 和 `token`。本机服务地址填 `http://127.0.0.1:端口号`，令牌只复制 token 值，不带两侧引号。
5. 点击“检查连接”，选择已安装模型，再点“保存连接，开始使用”。令牌或地址改动后需要重新检查。

新安装默认端口是 **8765**，若自己的配置是其他端口就以配置为准；迁移后的本机可能使用 **18765**。不要把 Ollama 的 **11434** 填成优诺服务端口，两者是不同服务。不要把 token、完整 config.json 或含令牌的截图公开分享。

## 5. 日常阅读

1. 确认 Ollama 运行，必要时双击 `start-host.cmd`。
2. 打开普通网页，选原文语言（可自动检测）和目标语言，点击“开始翻译”。当前支持中文、英语、日语、韩语作为目标语言。
3. 先翻译可见文字，向下滚动后继续处理。不是一次性提交整页，模型繁忙时需要等待或重试。
4. **译文**原位替换，**对照**保留原文方便核对；**原文**停止该网站持续翻译并恢复同来源已打开页面。

自动翻译记忆按“协议 + 主机 + 端口”区分。`https://example.com` 和它的子域名是不同网站来源。停止某个网站也会影响该来源的其他标签页，其他网站不受影响；设置页可以移除已记住的网站。

选中网页上的文字使用划词翻译，结果可复制，Esc 关闭。润色需要选中完整的已翻译文本节点，以便同时取得原文；不是对任意选区都能精译。

## 6. 更换模型和术语

进入设置，选择模型，点击“检查模型”，然后保存。若模型没安装，先运行对应 `ollama pull` 命令；仅下载不会自动切换优诺的选择。模型较慢时可试 3B，并用对照模式核对条件、否定和顺序。

“固定译法”用于指定某个词怎么翻译，例如 `workflow` → `工作流`；“保护词”用于保留产品名或缩写，例如 `ComfyUI`。每类最多 100 条、区分大小写，单词条最多 100 字符。URL 会自动保护。

导出设置适合备份模型和术语，不包含访问令牌，也不包含网站自动翻译列表；换浏览器仍需重新连接并启用网站。保存模型、术语后，已开启翻译的页面会按新设置处理。

## 7. 慢、连接不上或页面没变化

| 现象                          | 检查顺序                                                                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| “尚未安装/尚未初始化”         | 确认自己打开的是已安装的同一目录；该目录应有 `host/config.json` 和 `host/.venv/Scripts/python.exe`。首次使用运行 `install.cmd`  |
| Python 不存在或虚拟环境不可用 | 先检查 `python --version`，再用上面的 `-PythonPath` 指定可用 Python；已有损坏 venv 不会被安装器自动覆盖，应先备份配置再修复环境 |
| 无法连接优诺                  | 运行 `start-host.cmd`；核对配置中的 port 与连接地址；不要填成 11434                                                             |
| 令牌错误 / 401                | 从当前目录 config.json 重新复制，不要混用旧目录令牌                                                                             |
| Ollama 不可用 / 模型缺失      | 打开 Ollama，执行 `ollama list`；下载的名称必须与所选模型完全一致                                                               |
| 模型慢 / 忙 / 超时            | 用 `ollama ps` 查看是否落到 CPU；释放其他软件占用，先试较短选区或 3B；模型首次加载也会增加等待                                  |
| 提示旧后台版本仍在运行        | 先停止旧版本后台；仅重新加载浏览器扩展不能更新 Python 服务                                                                      |
| 扩展更新后无变化              | 在 `edge://extensions` 点击重新加载，再刷新已经打开的网页                                                                       |
| 页面始终不翻译                | 先检查是否为浏览器内部页、PDF、图片/Canvas、代码区或编辑区；这些不在当前支持范围                                                |

后台单次模型等待约 20 秒，前端约 25 秒；持续超时不应反复连点。停止翻译会丢弃晚到结果，但已经在 Ollama 执行的推理可能继续。

查看后台的直接报错，可以在项目根目录执行下面的前台启动命令。若后台已经运行，先使用 `uninstall.cmd` 停止它；该脚本同时取消登录自启，排错后需运行 `install.cmd` 恢复自启。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\host\start.ps1
```

端口冲突时，先停止本项目后台，备份并编辑 `host/config.json` 的 `port`（例如 18765），保留 token 和合法 JSON 格式，再启动并更新扩展连接地址。不要结束不明进程或将服务暴露到公网。

## 8. 升级、移动与卸载

升级前停止旧服务，备份 `host/config.json`，在设置页导出术语；覆盖更新时保留配置，再运行安装器，重新加载扩展并刷新网页。0.7.0 的卸载脚本可能漏掉相对路径启动的后台，需确认原服务窗口或对应进程已关闭。

建议长期使用一个目录。移动目录前从旧目录运行 `uninstall.cmd`，移动后在新目录运行 `install.cmd` 更新自启动路径，并在 Edge 重新加载新目录的 extension。Python 虚拟环境不保证可以直接跨目录迁移；如失效，应在新目录重建，而不是删除配置或模型。

卸载优诺时运行 `uninstall.cmd`，再在 Edge 删除扩展。脚本保留项目文件、token 和浏览器偏好；浏览器移除扩展可能清除其存储，先导出术语。Ollama 与下载的模型由用户单独管理，不随优诺卸载。

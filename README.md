# 优诺本地翻译插件

**简体中文** | [English](README_EN.md)

一款基于本机 Ollama 与 Qwen 的 Microsoft Edge 网页翻译扩展。网页文字只在自己的电脑上处理，不发送给云端翻译 API。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 持续自动翻译 | 对网站点击一次“开始自动翻译”后，滚动加载、动态新增文字、SPA 页面切换、子页面和新标签都会继续翻译。 |
| 三种阅读模式 | 可切换原文、译文或对照模式；对照模式会保留原文并紧跟标记译文，方便核对重要信息。 |
| 随时恢复原文 | 点击“原文”会停止该网站的持续翻译，并恢复已经替换的文字。 |
| 多语言互译 | 原文支持自动检测，也可手动选择中文、英文、日语或韩语；目标语言可自由选择。 |
| 本地 Qwen 模型 | 设置页可切换 Qwen2.5 3B 与 Qwen3 1.7B，均通过本机 Ollama 运行。 |
| 划词工具 | 选中网页文字后，可以单独翻译，也可以对现有译文进行润色。 |
| 术语规则 | 可以设置固定译法，并保护品牌名、产品名、代码标识等不希望翻译的词。 |
| 本地隐私 | 扩展只访问 `127.0.0.1` 上的优诺服务，由该服务调用本机 Ollama。 |

## 持续翻译逻辑

自动翻译按网站域名记忆：

1. 点击“开始自动翻译”，先处理当前可见文字。
2. 页面滚动或出现懒加载内容时，自动翻译新显示的文字。
3. 网站动态修改内容或进行 SPA 局部切换时，继续检测并翻译。
4. 进入同一网站的子页面或新标签页后，仍保持自动翻译。
5. 图标右下角三颗绿点依次闪烁表示正在翻译；完成或空闲时不显示绿点。
6. 点击“原文”后，停止该网站的自动翻译并还原文字。

其他网站不会受到影响。

## 环境要求

- Windows 10 或更高版本
- Microsoft Edge
- Python 3.10 或更高版本
- [下载 Ollama for Windows](https://ollama.com/download/windows)

## 下载模型

至少安装一个模型。仓库和安装包都不包含模型文件。

### Qwen2.5 3B（默认）

[Ollama 官方模型页面](https://ollama.com/library/qwen2.5:3b)

```powershell
ollama pull qwen2.5:3b
```

### Qwen3 1.7B（占用更小）

[Ollama 官方模型页面](https://ollama.com/library/qwen3:1.7b)

```powershell
ollama pull qwen3:1.7b
```

两个模型可以同时安装，然后在优诺设置页中随时切换。

## 安装教程

1. 下载仓库 ZIP 并解压，或者克隆仓库：

   ```powershell
   git clone https://github.com/chengjing84/younuo-local-translator.git
   ```

2. 双击项目根目录的 `install.cmd`。
3. 安装程序会生成本机随机访问令牌、启动后台，并设置登录 Windows 后自动启动。
4. 打开 `edge://extensions`。
5. 开启“开发人员模式”。
6. 点击“加载解压缩的扩展”，选择项目中的 `extension` 文件夹。
7. 打开优诺，根据首次运行页面完成连接检查。

需要手动启动后台时，双击 `start-host.cmd`。双击 `uninstall.cmd` 可以取消后台自启动；Edge 扩展仍需在扩展管理页手动删除。

## 使用教程

### 持续翻译网页

1. 打开普通网页并点击优诺图标。
2. 选择原文语言，或保留“自动检测”。
3. 选择目标语言。
4. 点击“开始自动翻译”。

### 划词翻译与润色

在网页中选中文字后：

- 点击“翻译”，使用当前 Qwen 模型单独翻译所选文字。
- 点击“润色”，优化已有译文的措辞和流畅度。

### 模型与术语设置

设置页支持：

- 切换已经安装的 Qwen 模型；
- 添加原词到译文的固定译法；
- 添加需要保持原样的禁止翻译词；
- 通过 JSON 导入或导出设置。

## 隐私与安全

- 翻译请求只发送到 `127.0.0.1` 上的优诺后台与本机 Ollama。
- `host/config.json` 包含随机生成的本机访问令牌，已被 Git 忽略，请勿上传或分享。
- 本机后台会校验扩展携带的访问令牌。
- 项目不包含统计分析、付费 API、账号系统或云端翻译服务。

## 已知限制

- Edge 禁止扩展在 `edge://extensions` 等内部页面中注入脚本。
- 图片或 Canvas 中绘制的文字无法直接翻译。
- 部分封闭 Shadow DOM 组件无法被浏览器扩展读取。
- 某些高频刷新 DOM 的网站可能导致个别文字被重新翻译。
- 翻译速度和质量取决于所选模型与本机硬件。
